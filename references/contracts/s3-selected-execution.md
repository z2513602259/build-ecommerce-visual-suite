# S3B selected-strategy execution contract

Use `workflow_stage: S3_SELECTED_STRATEGY_EXECUTION`. Strategy approval is true and identifies A, B, or C with an approval excerpt.

Reference the validated S3A package by path and SHA-256. Copy the selected option's approved strategy and final copy unchanged. Expand only that option's image briefs into complete independent image tasks.

Every task binds to an angle-matched current-product reference and immutable feature IDs, declares the least destructive generation method, scene design, ratios, full prompt, prohibitions, and current-product evidence. The task count and IDs must exactly match the selected option's briefs.

Run `complete_stage.py s3b <selected-strategy-package.json> <state.json>` to generate `selected-strategy-review.md`, `selected-strategy-handoff.md`, the updated review-package manifest, and the S3B state receipt. No second strategy approval is required when the expansion preserves the selected strategy exactly. Before S4, run `authorize_production.py` with the exact user request and approved asset IDs. “继续” or “确定” are not image-production requests.
