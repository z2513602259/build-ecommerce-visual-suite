# S3B fidelity task binding

Choose the least destructive method: real-product compositing, locked-product background replacement, multi-reference generation, then directly supported single-reference generation. Text-only recreation is prohibited.

Each task declares generation method, angle-matched primary reference, optional auxiliary references, immutable feature IDs, allowed changes, prohibited changes, angle-match explanation, and `结构推断风险: NONE`.

Generated images may support style continuity but never become the sole or primary product-identity source. If the requested view is unsupported, change the view or return to S1 for more current-product images.
